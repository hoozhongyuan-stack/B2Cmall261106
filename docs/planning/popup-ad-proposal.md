# 弹窗广告 提案

> 需求：小程序内居中弹窗广告，圆角、可点击跳转；后台可配置多条并分别开启；投放频次为「每人每天最多一次，打开小程序时检查」。
> 原则：先做「图片弹窗 + 统一链接 + 每日一次」，不做视频/人群定向；后台配置简单可控，避免打扰与误触。

---

## 一、需求理解与范围

| 能力 | P1 范围 |
| --- | --- |
| 样式 | 居中弹窗、圆角、遮罩、右上角关闭按钮、出入场缩放动画 |
| 内容 | 单张图片（素材库），可选标题/替代文案 |
| 跳转 | 复用微页面统一链接体系（微页面/商品/分类/搜索/优惠券/门店/内置页面等） |
| 数量 | 后台可配置多条，每条独立启用/停用 |
| 频次 | 每条广告每天最多展示一次；多条启用时按优先级依次弹出，逐条关闭 |
| 展示位置 | 仅首页（旧版首页与微页面首页都生效） |

**不做（P1）**：视频弹窗、多图轮播、按页面/人群投放、曝光点击报表、倒计时关闭。

---

## 二、展示策略（已确认）

1. **触发时机**：进入首页并完成首屏渲染后约 400ms 开始判断，避免和首页数据加载抢资源。
2. **多条启用**：所有「启用 + 在投放时间内」的广告都要展示，按「优先级高 → 创建时间新」排队，**一次只显示一张**；用户关闭当前弹窗后，间隔约 200ms 再显示下一张。
3. **每天一次的口径**：以**单条广告**计，每条广告每天最多展示一次；当天已看过的广告不再弹出，未看过的继续排队。
4. **每次打开的定义**：
   - 小程序冷启动进入首页时检查；
   - 从后台切回前台（间隔 ≥30 分钟）再次进入首页时检查；
   - 当日已看过的广告自动跳过。
5. **关闭方式**：仅右上角 × 关闭；点击图片执行跳转并关闭当前弹窗。点击遮罩**不关闭**（避免误触）。
6. **记录时机**：每条广告**实际展示**时立刻写入「今日已看」，而不是关闭时，避免用户不关就反复弹。
7. **跳转中断**：若用户点击图片跳转到其他页面，当前广告记为已看，剩余未展示的广告本次会话不再继续弹；下次打开（或次日）再按队列展示。

## 三、后台设计

### 3.1 入口与页面

```
装修
├─ 页面装修
├─ 底部导航
├─ 弹窗广告      ← 新增
└─ 素材库
```

列表字段：缩略图、名称、优先级、投放时间、状态（启用/停用）、更新时间、操作（编辑 / 复制 / 删除 / 启用开关）。
顶部操作：新建弹窗；启用数量上限提示（最多 10 条）。

### 3.2 编辑表单

| 字段 | 说明 |
| --- | --- |
| 名称 | 内部备注，≤20 字，不对外展示 |
| 弹窗图片 | 素材库选图，必填；**统一 3:4（如 750×1000）**，≤5MB |
| 替代文案 | 选填，图片加载失败时展示 |
| 点击跳转 | 统一链接选择器；不跳转也合法 |
| 优先级 | 整数，越大越优先，默认 0；决定多条弹窗的展示顺序 |
| 投放时间 | 开始/结束时间，均可留空表示不限 |
| 启用 | 开关；停用后立即不再下发 |

右侧手机预览：375px 画布，居中圆角弹窗 + 关闭按钮 + 遮罩，实时预览。

### 3.3 校验

- 图片必须来自素材库；
- 链接复用微页面链接校验（目标存在、商品在售、页面在白名单内）；
- 启用条数 ≤10；同一时间允许多条启用；
- 优先级、时间区间合法性校验。

权限：`SUPER` / `OPS` 可写，`CS` 只读（与装修一致）。

## 四、数据模型

```prisma
model PopupAd {
  id        String    @id @default(cuid())
  name      String
  imageKey  String
  alt       String?
  /// 统一链接：{ type, value }
  link      Json      @default("{}")
  priority  Int       @default(0)
  enabled   Boolean   @default(true)
  startAt   DateTime? @db.Timestamptz(3)
  endAt     DateTime? @db.Timestamptz(3)
  deletedAt DateTime? @db.Timestamptz(3)
  createdAt DateTime  @default(now()) @db.Timestamptz(3)
  updatedAt DateTime  @updatedAt @db.Timestamptz(3)

  @@index([enabled, priority])
  @@index([deletedAt])
}
```

> 频次不在服务端建表：P1 由客户端本地记录「今日是否已看」，无需登录信息，零额外请求；P2 如需统计/服务端频控，再加 `PopupAdExposure` 表。

## 五、接口设计

### 5.1 小程序（公开）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/popup-ad/active` | 返回当前所有可展示广告 `{ ads: [...], serverDate }`，按优先级排序；无可用广告时 `ads: []` |

- 服务端按 `enabled=true + 未删除 + 投放时间命中` 过滤，按 `priority desc, createdAt desc` 排序，最多返回 10 条。
- 客户端再用本地记录过滤掉「今天已看」的广告，依次展示。
- 返回 `serverDate`（`YYYY-MM-DD`，Asia/Shanghai）作为频次判断基准，降低改设备时间的影响。
- 缓存 60s；发布/启停后 1 分钟内生效。

### 5.2 后台

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/admin/popup-ads` | 列表（名称/状态/分页） |
| POST | `/admin/popup-ads` | 新建 |
| GET | `/admin/popup-ads/:id` | 详情 |
| PUT | `/admin/popup-ads/:id` | 保存 |
| PATCH | `/admin/popup-ads/:id/enabled` | 行内启用/停用 |
| POST | `/admin/popup-ads/:id/duplicate` | 复制（P1.5） |
| DELETE | `/admin/popup-ads/:id` | 软删除 |

## 六、小程序实现

### 6.1 组件与挂载

- 新增 `components/PopupAd`：遮罩 + 弹窗卡 + 图片 + 关闭按钮；内部维护「待展示队列」。
- 挂在首页（`pages/home/index`，旧版与微页面两个分支都渲染一次），仅首页展示。
- 展示条件：`/popup-ad/active` 返回若干广告，过滤掉本地已看过的，按顺序入队；展示第一张，关闭后 200ms 展示下一张。
- 每张广告实际展示时立即写入本地已看列表。
- 弹窗打开时锁定背景滚动，关闭恢复。

### 6.2 视觉规范

- 遮罩：`rgba(0,0,0,0.55)`；弹窗宽度 80%（最大 620rpx），圆角 24rpx，白色底。
- 图片：`aspectFill`，宽度 100%，高度按上传比例自适应；加载失败展示替代文案。
- 关闭按钮：右上角圆形 44×44rpx，半透明黑底白 ×，位于弹窗内右上角，避免被裁切。
- 动画：`scale(0.92) + opacity` → `scale(1) + opacity(1)`，200ms。
- 安全区：底部留 `env(safe-area-inset-bottom)`。

### 6.3 频次存储

```ts
// 本地键：shanye_popup_seen
{ date: '2026-11-11', adIds: ['ad_1', 'ad_2'] }
```

- 判断：`seen.date === serverDate && seen.adIds.includes(ad.id)` 则跳过该条。
- 每展示一条就把 id 追加进去；跨天后日期不一致，视为全部未看。
- 广告被删除/停用后，其 id 留在列表里无影响，可定期清理。

### 6.4 跳转

- 复用 `utils/microLink.ts` 的 `openMicroLink`；点击图片 → 关闭弹窗 → 跳转。
- `none` 类型时点击图片不跳转，仅关闭按钮可关闭。

## 七、测试与验收

**契约测试**

- 仅返回启用且时间命中的广告；多条启用时按优先级返回列表；
- 停用/删除/未开始/已结束不返回；
- 图片与链接校验：外链图片、失效商品、非法页面路径均 400；
- 启用数量上限。

**E2E**

1. 后台上传图片、配置链接并启用 → 小程序首页弹出，图片与跳转正确；
2. 多条启用 → 按优先级依次弹出，关闭一张后出现下一张；
3. 逐条关闭后刷新页面，当天不再重复弹；
4. 模拟次日（修改本地 `shanye_popup_seen` 日期）→ 再次弹出；
5. 停用某一条 → 该条不再弹，其余启用广告照常；
6. 点击图片 → 跳转目标页并关闭当前弹窗，剩余广告本次会话不再弹。

**验收标准**

- 首屏渲染后 1s 内完成弹窗判断，无白屏/闪烁；
- 弹窗不遮挡底部自绘导航（层级低于导航与登录引导）；
- 每日最多 1 次，跨天自动恢复。

## 九、风险与对策

| 风险 | 对策 |
| --- | --- |
| 打扰用户 / 误触 | 每条每天仅一次、仅首页、关闭按钮固定可见、遮罩不关闭 |
| 弹窗层遮挡底部导航或登录引导 | 层级低于 TabBar 与登录跳转；首页登录判断优先于弹窗 |
| 缓存导致停用后仍展示 | 接口 60s 缓存 + 客户端每次启动强制拉取，可接受 1 分钟延迟 |
| 图片过大拖慢首屏 | 建议 750×1000、≤5MB；懒加载，加载失败显示替代文案 |
| 广告合规 | 图片右下角预留「广告」标识位；P1 由运营在图中自行添加 |
| 设备时间被修改 | 使用服务端 `serverDate` 判断日期；P2 服务端记录曝光 |

---

## 十、决策结论

已确认，可按 P1 实施：

1. **多条启用**：全部展示，按优先级依次弹出，用户逐条关闭；频次按单条广告每天一次计算。
2. **展示位置**：仅首页。
3. **关闭方式**：仅右上角 ×，点击遮罩不关闭。
4. **图片规格**：统一 3:4。
