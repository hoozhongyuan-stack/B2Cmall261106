Design System · v1.2

颜值不是装饰，是约束。
一套可复用的判断标准。

这份规范定义「山野商城」双端的视觉语言：先定一个视觉命题，再用字体、间距、配比与动效把它锁死。任何人新增页面时，只要遵守下面 12 条自检，就不会把界面做丑。

品牌 山野（演示，可替换） 端 微信小程序 + 管理后台 基准 375 / 1280 日期 2026-11-06

01颜值怎么保证

六条硬约束 + 一份 12 条自检清单。设计、评审、实现、走查都对照它，而不是靠「感觉好看」。

01
一屏一个主导元素
每屏只允许一个视觉重心：一张大图、一个数字、一张表。其余元素降为辅助，禁止并列三个同等抢眼的东西。
02
排版先于组件
先定字号阶梯、行高与间距节奏，再往里塞按钮和卡片。字号乱，组件再精致也救不回来。
03
颜色按 90 / 8 / 2 配比
90% 中性（浅灰、白、墨、线），8% 品牌正红只给动作与价格，2% 金色只给会员标识。超出比例就是「花」。
04
图片即装饰，不另加特效
所有氛围由实拍图承担。禁止渐变背景、玻璃拟态、彩色投影、漂浮卡片——它们是最快的「廉价感」来源。
05
动效只有三个通道
进入、悬停、切换。时长与缓动写死在同一张表里，不许每页自定义，动效一多就变噪音。
06
状态必须画出来
空态、加载、错误、禁用、超长文本，每类都要有设计。只画「最理想状态」的稿子，落地一定难看。

12 条自检（每轮交付必跑）

  • 遮住 Logo 和导航，第一屏还能认出是谁吗？品牌感
  • 这一屏去掉图片后还成立吗？成立说明图太弱。视觉锚点
  • 只读大标题和数字，能看懂这页在干什么吗？可扫读
  • 每个区块是否只有一个职责（说明 / 证明 / 深化 / 转化）？信息结构
  • 每个卡片是否都不可替代？能变成分隔线或列表就删掉卡片。克制
  • 页面有超过 1 个强调色在用吗？色彩纪律
  • 去掉所有投影，还是高级的吗？材质
  • 字号是否只用了字阶里的 5 档？行高是否都来自同一套比例？排版
  • 价格、数量、金额是否右对齐且等宽数字？数字
  • 空 / 错 / 载 / 禁 四态是否都有稿？完整性
  • 键盘 Tab 一圈，焦点是否看得见、顺序是否合理？可达性
  • 开启「减少动态效果」后，界面是否仍然完整？动效降级
评审方式：设计稿 → 对自检清单逐条打勾 → 前端实现 → 用 web-design-guidelines 代码审查 → 截图视觉回归。四步都过才算「完成」，而不是「画完了」。

02视觉命题

一句话描述气质、材质与能量，双端共用同一句。

移动端：「红白商业感 + 编辑留白」——浅灰底、纯白卡、正红只给动作与价格，宋体大标题保留选品气质。
后台端：「Linear 式克制」——近白画布，发丝分隔，正红单一强调，信息密度优先。
共同点：不用渐变背景、不用彩色投影堆叠；红色出现的位置永远只代表「可以点」或「这是价格」。

交互命题（只有三个）

  1. 进入：首屏图文分层浮现——图先到，标题延迟 60ms 跟上，200ms 内结束。
  2. 悬停：商品图 1.02 缓慢放大，价格与文字不动，制造「可以点」的暗示。
  3. 切换：屏与屏之间淡入 + 上移 6px，一次 180ms，永不使用左右滑动。

配比与禁用

中性 90% 品牌红 8% 2%

后台端使用纯白 #FFFFFF 画布（不要灰底），仅靠发丝线与留白分区；其余色值完全共用，保证两端像一个产品。

禁止原因替代方案
彩色渐变背景抢走商品图注意力，廉价感主要来源浅灰底 + 一张实拍
彩色投影 / 玻璃拟态复杂背景上不可控，且降低文字对比白块浮起 + 极浅分隔
三种以上强调色用户无法判断哪个该点只留正红（动作 + 价格）+ 金色（会员）
整屏卡片堆叠信息密度被卡片内边距吃掉白块分组 + 大间距，不画外框
满屏 1px 分隔线线条一多就沉闷、显低价用底色块与留白分组，线只留在块内

07图片规范

图片是这套设计唯一的「彩色来源」，所以标准要最严。

规则要求
背景暖白、亚麻、木色、灰泥；不用纯白棚拍与彩色渐变
主体一个商品居中偏下，留出上方 15% 呼吸区
文字图内禁止出现文字、Logo、价格、水印
比例商品 1:1，场景 4:3，首页 Hero 3:2 裁切
加载固定宽高防抖；首屏优先加载，屏外懒加载；底色用 #E8E4DA
数量一屏最多一张大图；商品列表图不得加边框与投影

08动效

三个通道，两个时长，一条缓动。写进实现里，不靠临场发挥。

进入 · Enter

图片先出现，文字延迟 60ms 跟上，整体 200ms 结束。用于首屏与屏切换。

opacity 0→1 · translateY 6px→0

悬停 · Hover

商品图 1.02 放大，320ms ease-out；文字、价格、边框不动。

transform: scale(1.02)

切换 · Switch

分段控件与侧栏激活项用底色渐变过渡，200ms，不做滑动指示条。

background-color 200ms cubic-bezier(.2,.7,.3,1)

降级 · Reduced Motion

检测到系统「减少动态效果」时，位移与缩放全部取消，仅保留 120ms 透明度。

@media (prefers-reduced-motion: reduce)

禁用清单

  • transition: all（必须逐项声明属性）
  • 超过 400ms 的界面过渡、弹跳/回弹缓动
  • 循环播放的装饰动画（呼吸、闪烁、漂浮）
  • 滚动视差与视差背景

09双端节奏对照

同一个品牌，两种呼吸频率：移动端慢而疏，后台快而密。

维度小程序（慢）后台（快）
首屏整幅图 + 两行字 = 海报直接进工作台：指标带 + 待办 + 表格
信息密度每屏 1 个任务每屏 3–5 个可比较对象
分隔方式留白为主，少用线发丝线为主，少用留白
强调色只在价格与主按钮只在主按钮与激活导航
标题字体宋体，有编辑感无衬线，工具感
动效进入 + 悬停两处仅切换 + 弹层两处

10无障碍与可用性基线

以下为交付硬门槛，实现完成后按 web-design-guidelines 逐条核对。

项目要求验收方式
焦点可见所有可交互元素 :focus-visible 2px 正红描边 + 2px 偏移；禁止 outline:none 无替代键盘 Tab 走查
